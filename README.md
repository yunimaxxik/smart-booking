# 🏢 Smart Booking — Система бронирования переговорных комнат

## 🎮 О проекте

**Smart Booking** — это современное, производительное и интуитивно понятное SPA-приложение для автоматизации бронирования переговорных комнат в корпоративной среде. Сервис спроектирован для оптимизации рабочего пространства, позволяя сотрудникам мгновенно находить свободные локации, фильтровать их по характеристикам и резервировать удобные временные слоты.

Архитектура проекта построена по методологии **Feature-Sliced Design (FSD)** с четким разделением клиентского и серверного состояния. Кодовая база полностью типизирована на **TypeScript**, что гарантирует строгую типобезопасность, чистоту бизнес-логики и стабильность приложения при масштабировании.

### 🔥 Ключевые возможности

* **Интерактивный Dashboard**: гибкий каталог пространств с динамической фильтрацией параметров в реальном времени и автоматической синхронизацией серверного кэша.
* **Надежная авторизация**: защищенный доступ к функционалу (`ProtectedRoute`), валидация пользовательского ввода и безопасная работа с JWT-токенами.
* **Управление временными слотами**: наглядный выбор дат, проверка занятости переговорных комнат и бронирование требуемых интервалов без пересечений.
* **Модульный Layout**: адаптивная панель навигации с отслеживанием активных маршрутов и вложенным рендерингом страниц через `<Outlet />`.
* **Отказоустойчивые UI-состояния**: информативная визуализация этапов работы с данными — скелетоны при загрузке, сценарии ошибок и плавный вывод списков.
* **MSW (Mock Backend)**: изолированная симуляция реального REST API на уровне Service Worker для независимой и быстрой клиентской разработки.

## 🛠 Технологический стек

Проект реализован с использованием передовых практик и актуального стека фронтенд-разработки:

* **React 19** — компонентная библиотека для создания интерфейсов с декларативным подходом.
* **TypeScript** — сквозная строгая типизация (дженерики ответов API, discriminated unions, utility types).
* **Vite** — сверхбыстрый сборщик нового поколения с оптимизированной компиляцией модулей.
* **TanStack Query (React Query)** — декларативное управление асинхронным серверным стейтом, умное кэширование и ревалидация данных.
* **Zustand** — легковесный и предсказуемый менеджер глобального клиентского состояния.
* **React Router v6** — декларативная маршрутизация с поддержкой вложенных роутов и приватных экранов.
* **Tailwind CSS** — утилитарный фреймворк для быстрой, гибкой и адаптивной верстки.
* **React Hook Form + Zod** — производительная работа с формами без лишних ререндеров и строгая валидация схем данных.
* **date-fns** — современная модульная библиотека для точных манипуляций с датами и временем.
* **MSW (Mock Service Worker)** — бесшовное перехватывание сетевых запросов и мокирование REST API.
* **ESLint & Prettier** — автоматический статический анализ кода, поддержание чистоты и единого стиля оформления.
