# 🏢 Smart Booking — Система бронирования переговорных комнат

**Smart Booking** — это современное SPA-приложение для бронирования переговорных
комнат в офисе. Пользователи могут просматривать доступные комнаты, фильтровать
их по параметрам и бронировать временные слоты на конкретную дату.

Проект реализован с использованием современных подходов: Feature-Sliced Design,
TypeScript, React Query для серверного состояния и Zustand для клиентского.

---

## 🛠 Технологический стек

**Frontend:**

- React 18 + TypeScript
- Vite (сборщик)
- Tailwind CSS (стилизация)
- React Router v6 (роутинг)
- React Query / TanStack Query (работа с API)
- Zustand (глобальный стейт)
- React Hook Form + Zod (формы и валидация)
- date-fns (работа с датами)

**Инструменты:**

- MSW (Mock Service Worker) — моки API
- ESLint + Prettier (линтинг и форматирование)

## ✨ Ключевые особенности

- **Реализована полноценная система авторизации** с защитой маршрутов: форма
  логина валидируется через React Hook Form + Zod, JWT-токен хранится в Zustand
  и localStorage, компонент `ProtectedRoute` перенаправляет неавторизованных
  пользователей на страницу входа.
- **Разработан Dashboard с фильтрацией комнат** в реальном времени: клиентское
  состояние фильтров (Zustand) синхронизируется с серверным кэшем (React Query)
  через динамический `queryKey`, что обеспечивает автоматический рефетч данных
  при изменении параметров.
- **Настроена архитектура Feature-Sliced Design** с разделением кода на слои
  (`app`, `pages`, `widgets`, `features`, `entities`, `shared`), что
  обеспечивает масштабируемость и изоляцию бизнес-логики.
- **Создан компонент Layout с адаптивным Sidebar**, использующий `useLocation`
  из React Router для подсветки активного пункта меню и `<Outlet />` для
  вложенного рендеринга дочерних страниц.
- **Реализован виртуальный бэкенд через MSW**, который перехватывает
  HTTP-запросы на уровне Service Worker и возвращает моковые данные, что
  позволяет разрабатывать фронтенд независимо от реального API.
- **Настроена обработка состояний загрузки и ошибок** в React Query: компонент
  `RoomList` отображает skeleton-лоадер при `isPending`, текст ошибки при
  `isError` и список карточек при `isSuccess`.
- **Написана типобезопасная работа с API** с использованием TypeScript:
  дженерики для ответов сервера, discriminated unions для состояний запросов,
  utility types (`Pick`, `Omit`, `Partial`) для переиспользования интерфейсов.
